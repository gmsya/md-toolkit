新主题与排版技巧首发于公众号「顾明同学」。

  • 0.5.0
    把一个 Markdown 文件夹变成可浏览、可搜索、可换主题的静态站点。
    新增
    • 文件夹一键生成静态站点：递归扫描 Markdown，自动生成导航树、每页目录与客户端搜索，公式和图表沿用编辑器渲染
    • 文件夹右键直接生成；命令面板运行时弹出文件夹选择；目录已存在时弹覆盖确认
    • 没有 index.md 时自动生成可点击首页；首页居中聚焦、搜索居中
    • 四套主题（暖白、冷白、暗、护眼绿）自定义下拉切换，默认跟随系统明暗，手动选择记忆
    • 文档站三栏排布：左导航当前页高亮，右置本页目录随滚动高亮、不截断，正文放宽
    • 搜索：标题与正文都搜，分词顺序不限、不连续字符模糊匹配，片段标命中词、点击跳到命中文字高亮；↑/↓ 选、Enter 打开、Esc 收起，Ctrl+K 或 / 聚焦，无匹配提示，标题命中优先
    • 阅读流：上一篇/下一篇、标题悬停锚点复制链接、返回顶部、代码块一键复制、外链新窗打开带 noopener
    • 命令 md-toolkit.buildSite 支持 source/destination/overwrite，可脚本化指定输入输出；默认生成到源目录的 _site
    修复
    • 修复双击直开（file://）时搜索无反应的问题
    • 修复子页搜索结果链接指向错误目录的问题
    • 重新生成自动清理孤儿页，不拷贝隐藏文件（.env 等）
    • 代码示例里的 href 不再被站内链接改写误伤
    • mermaid 跟随主题配色，暗色不再浅底
  • 0.4.6
    本轮修复五处问题，并把打字机开关移到状态栏。
    修复
    • 修复打开外部文档时其中的脚本可能被执行的安全问题
    • 修复图片和链接地址在格式化或保存后被改写的问题
    • 修复用 Windows 换行格式的画板文件保存后反复整板重载的问题
    • 修复部分文档的 frontmatter 在编辑后多出空行的问题
    • 修复画板折叠组导出时丢失成员和连线的问题
    优化
    • 打字机开关移到状态栏，只在编辑时出现
  • 0.4.5
    画板这轮补齐了上手引导、文字编辑、分支标签与视口记忆。
    新增
    • 便签与自由文字改为 Enter 换行，Ctrl/Cmd+Enter 完成
    • 编辑框随内容增高，下方显示换行、完成与取消提示
    • 判断框出线后可直接选是、否或自定义标签，已有一条时默认另一半
    • 形状面板显示最近使用与悬停名称
    • 空板时形状钮带高亮引导
    • 画板按文件记住上次视口，重新打开回到原位
    • 大板在小窗首次打开保持可读缩放，矮窗工具条分两列显示全部工具
    修复
    • 修复缩略导航点按或拖动时画布往反方向跳的问题
    • 修复缩略导航全览时当前位置框显示不全的问题
    • 修复判断框手标一条是/否后，另一条丢失自动标签的问题
    • 修复矮窗口首次打开时内容可能被工具条挤出视口的问题
  • 0.4.4
    编辑手感补齐：结构不坏、焦点不丢、徽章可用；画板导航与连接、编辑开关向主流工具靠齐。
    新增
    • 行内状态徽章：标题/正文/列表挂彩色 chip，点 chip 改字、换色、删除
    • 画板：minimap 缩略导航（点/拖定位视口）、分组折叠（+N 胶囊，成员与绑线同隐）、Alt 轮廓任意连接点、形状搜索（名称/拼音/首字母）、持续适应画布开关
    • 编辑器：代码块行号/折叠开关、打字机模式（光标行垂直居中，默认关）
    修复
    • 引用、表格、跨块上色不再弄坏结构
    • 焦点不丢：Tab 保焦、点空白光标落文末、折叠箭头 hover 常驻
    • 手敲加粗/反引号不再被自动配对多加符号
    • 重装/切源码时序不再写空文档；浮层浮条贴边翻转、窄屏不裁切不挤字
    • 画板双击编辑：浮层按内容自尺寸，加粗/缩放不再裁成尾字；光标落双击点
    • git/conflictResolution 比对副本只读：画板与 md 编辑器能看不能改，防误改冲突视图
    优化
    • 行内语法失焦即渲染；整行回车快捷建代码块/分割线
    • 表格面板全键盘操作；块手柄带类型徽标
    • 表格按内容自适应宽；插表面板锚光标块，不跑屏幕左上
    • 清除格式一键剥净、格式刷刷到下一处选区；代码块换行开关与表格等分列宽
    • PDF 导出徽章保住圆角与内边距
    • 格式刷双击连续刷、清除格式快捷键、选区字数；链接浮条补复制（结果就地反馈）
    • 斜杠菜单拼音搜索/最近使用/上下文裁剪；粘贴 Markdown 先询问再转换；中文数字列表与空格闭符号快捷
    • 公式渲染失败明示错误态（红标+原文），点击回源就地改；画板选中态 Enter 进编辑
    • 画板：悬停未选中连线显段把手、免选中直接拖段出折点；持续 fit 随内容跟新、手动平移/缩放退出
    • 导出命令收脚本化入参（source/destination/overwrite），裸 Uri 向后兼容；目标已存在未声明覆盖即拒
  • 0.4.3
    打字、拖拽、连线这些日常动作跟手了。
    修复
    • 双击图形改一个词，不再整句被选中重打
    • 拖导图节点时，被拖的那枝跟着手走
    • 方向键连按后重做，回到挪完的位置
    • 笔刷锁定连续勾画，收笔不再跳回选择
    • 按住 Ctrl 只点一下不再多出隐藏副本，拖动才复制
    • 连线落回起点或太短，起点闪一下红环，不再无声
    • 查找与替换不再每敲一个字就跳页面，跑偏的命中也会露出来
    • 块手柄随滚动走，滚出视野或指针离开正文后照常收起
    • 输入框不再吞掉中文候选词
    优化
    • 快捷键速查卡补上方向键微调、Ctrl 拖动副本、Shift 加选与导图建树键

    • Shift 框选改为切换选中状态
    • 按住 Shift 的方向键按网格间距移动
    • 从工具条拖出元素或手绘到画布边缘时，画布自动滚动
